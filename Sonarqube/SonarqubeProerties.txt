========================================
GENERIC PROJECT (CLI)

sonar.projectKey=my-project-key
sonar.projectName=My Project
sonar.projectVersion=1.0

sonar.sources=src
sonar.tests=src/test

sonar.sourceEncoding=UTF-8

sonar.exclusions=/node_modules/,/build/,/dist/

sonar.host.url=http://localhost:9000

sonar.login=YOUR_SONAR_TOKEN

========================================
MAVEN (JAVA) – CLI USAGE

sonar.projectKey=my-java-maven-project
sonar.projectName=Java Maven Project
sonar.projectVersion=1.0

sonar.sources=src/main/java
sonar.tests=src/test/java

sonar.java.binaries=target/classes

sonar.junit.reportPaths=target/surefire-reports
sonar.coverage.jacoco.xmlReportPaths=target/site/jacoco/jacoco.xml

sonar.sourceEncoding=UTF-8

sonar.host.url=http://localhost:9000

sonar.login=YOUR_SONAR_TOKEN

sonar.coverage.jacoco.xmlReportPaths=backend/target/site/jacoco/jacoco.xml

sonar.login=YOUR_SONAR_TOKEN

========================================
DOTNET (ONLY IF USING GENERIC SCANNER – NOT RECOMMENDED)

sonar.projectKey=my-dotnet-project
sonar.projectName=My DotNet Project
sonar.projectVersion=1.0

sonar.sources=.
sonar.exclusions=/bin/,/obj/

sonar.cs.opencover.reportsPaths=**/coverage.opencover.xml

sonar.sourceEncoding=UTF-8

sonar.host.url=http://localhost:9000

sonar.login=YOUR_SONAR_TOKEN

========================================
NOTE FOR DOTNET (RECOMMENDED METHOD)

For .NET projects, use:

dotnet sonarscanner begin
dotnet build
dotnet test
dotnet sonarscanner end

Instead of sonar-project.properties.
